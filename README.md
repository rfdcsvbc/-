# 中秋祝福动画页面

这是一个单文件 HTML 中秋祝福页面，针对手机竖屏布局，也支持桌面浏览器。页面中的样式、动画和交互脚本都写在 `index.html` 内，不依赖外部图片、字体、CDN 或其他资源。

## 预览

用浏览器打开同目录下的 `index.html` 即可预览。触摸或点击页面会触发金色涟漪和粒子飞溅。

## 页面效果

- 蓝紫色星云夜空、闪烁星星和连续流星
- 呼吸发光的金色圆月与缓慢扫过的月光
- 漂浮金色粒子、桂花花瓣和随机粒子爆发
- 逐字显示的「中秋快乐」、延迟祝福文案与流光效果
- 手机触控和桌面点击涟漪交互
- 支持系统的减少动态效果设置

## 发布到 GitHub Pages

1. 在 GitHub 创建一个仓库。
2. 将 `index.html` 上传到仓库根目录并提交。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择从分支部署，分支选 `main`，目录选 `/(root)`，然后保存。
5. 等待 GitHub Pages 完成部署；页面地址会显示在该设置页。通常格式为 `https://<用户名>.github.io/<仓库名>/`。

如果把仓库命名为 `<用户名>.github.io`，页面地址通常为 `https://<用户名>.github.io/`。

## 文件

- `index.html`：可直接预览和部署的完整页面。
- `README.md`：页面说明与发布步骤。
